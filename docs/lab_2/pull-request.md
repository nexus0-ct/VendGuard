# ЛР2: сенсорна підсистема VendGuard

VendGuard реєструє покупця через PIR, удар по корпусу через MPU6050 та світлову ознаку відкриття сервісного відсіку через ADC. Покупець створює INFO. Світлова ознака створює ALARM в охороні та INFO під час обслуговування; удар діє в обох режимах.

Додано розкладку пінів, калібрування, фільтрацію та гістерезис, незалежну обробку каналів, журнал на 64 записи, самоперевірку, UART-команди та відновлення MPU6050 після NACK. Sensors і Logic відокремлено від STM32 HAL; Board реалізує апаратний доступ і розклад опитування.

Перевірка: ARM-збірка Docker, 15 груп хостових тестів, ASan/UBSan, перевірка шарів і підключень. Покриття GCC: 100% рядків усіх чотирьох переносних модулів, 95,24–100% напрямків гілок. GitHub Actions виконує збірку, тести та контроль покриття.

Wokwi-записи підтверджують ID 0x68, шестибайтне читання, UART, PIR, маркер ADC, режими, одночасні події, адресний NACK та відновлення. Збережено VCD, sigrok .sr, налаштування PulseView, декодування і SHA-256 оригіналів. Фізичні електричні вимірювання не входять до цифрової перевірки.
