# Результати ЛР1 і ЛР2

Шостак Богдан, ІО-36, №20. ЛР1 злито в main через PR №1. Вона задає Nucleo-C031C6, UART2, LED та Docker-збірку. Її звіт зберігається окремо від ЛР2.

ЛР2 інтегрує PIR PA10, MPU6050 PB8/PB9, LDR PA0 та маркер ADC PA4. Реалізовано калібрування, незалежні канали, охорону/обслуговування, журнал, самоперевірку, UART-команди та відновлення після NACK. Повні сигнали записано у Wokwi, фрагменти відкрито в PulseView.

15 груп хостових тестів, ASan/UBSan, покриття та GitHub Actions перевіряють реалізацію. Залежності Docker та checkout зафіксовано. Десять комітів групують підключення, шари, драйвер, детектори, режими, виконання, тести, CI і звіт. Тег lab2 позначає кінцевий комплект.
