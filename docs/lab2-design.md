# Правила VendGuard

Покупець є інформаційною подією. PIR, удар і світло обробляються окремими умовами; одночасні умови дають окремі записи.

| Правило | Критерій | Інженерна причина |
|---|---|---|
| PIR | LOW→HIGH; опитування 5 мс | Один запис на імпульс, без потоку при HIGH |
| MPU | 100 Гц; ±2g, DLPF 44 Гц | Окремий темп для коротких змін корпусу |
| Калібрування | 100 стабільних samples; модуль 0,9–1,1g; розмах осі ≤100mg | Вектор гравітації входить до фону; рух перезапускає накопичення |
| Удар | Норма відхилення від фону ≥650mg і зміна між samples ≥250mg | Запас від шуму; повільна зміна положення не є коротким ударом |
| Rearm удару | Відхилення ≤150mg неперервно 300 мс | Тривалий вплив дає одну подію, новий удар після спокою |
| LDR | 50 Гц, EMA 1/4; фон 50 samples | Світло в закритому відсіку калібрується на старті |
| Світлова ознака | ADC падає від фону ≥600 counts протягом 400 мс | Освітлення знижує AO; короткі коливання відсікаються |
| Rearm світла | Відхилення ≤300 counts протягом 400 мс | Гістерезис запобігає повторним записам біля порогу |
| Режим | Команди guard / service | Явний навчальний вибір оператора |
| Відмова MPU | Перша помилка дає FAULT, повторна ініціалізація кожну 1 с | Дані помилки не беруть участі в обчисленні удару |
| Журнал | 64 записи в RAM, overwrite oldest | Обмежена пам’ять STM32, окремий лічильник тривог |

Це параметри навчального стенда, а не сертифікований захист автомата. Для фізичного корпусу поріг удару налаштовують за записами його вібрації. ADC counts є відносною світловою ознакою, без обіцянки каліброваних lux. Світло у service дає SERVICE_ACCESS, у guard SERVICE_OPEN_SUSPECTED. Удар діє в обох режимах.

Режим не авторизує особу. Перехід у guard за вже підтвердженої відкритої ознаки дає одну світлову тривогу. Перехід у service за цієї ознаки дає одну SERVICE_ACCESS. Команда того самого режиму не створює дублікати.

FR-01 перевіряє startup/heartbeat, FR-02–03 PIR і незалежний alarm count; FR-04 калібрування/удар; FR-05–06 світло/режими; FR-07 категорії/час/джерело; FR-08 спільні впливи; FR-09 помилки/відновлення.
