# Старт із тестовою I²C-моделлю

01.11.2026: окремий Wokwi стенд, ELF `vg3-eed2dae477f4fd8f`, SHA-256 `b6681b1a211dcd06cc175925fb4d651db004903671e63df4c761d41684c46ca0`; прошивка не змінена. Власна спрощена модель на адресі 0x68 замінює MPU: повертає NACK до 3 секунд симулятора, далі ACK, WHO_AM_I=0x68 та сталий вектор (0,0,1g). Записані лише мінімальні потрібні регістри, модель не відтворює фізику чи повний протокол реального датчика. Rust source SHA-256 `f60873a135cd87327deb4d5784f0c4a1a374bc082b650ceb528e942d602da374`, WASM SHA-256 `1ef0096fbc4bfa85928ab62cc2299be3be11f9e1bdd2b80c789667ca08ad9335`. `wokwi.toml` і `diagram.json` фіксують стенд; D0 UART TX, D1 SCL, D2 SDA.

VCD SHA-256 `36149af69873ccb251c7671da38781c4e7538a06d4c7b47e8f51f709b0bfd4c8`, без втрат запаковано gzip. Незалежний декодер I²C (`decode_i2c.py`, результати `i2c-transactions.json`) дає адресний байт d0 NACK на 0,035900; 1,085812; 2,086632 с, d0 ACK та регістр 75 на 3,086635 с, d1 ACK і дані 68 на 3,086887 с. Перша вибірка d1: 00 00 00 00 40 00 на 3,096366 с. Останній NACK читання — звичайне завершення читання master.

`startup-decoded.uart_tx.txt` є похідною UART із VCD, не окремим raw serial; MCU повідомляє MPU_FAILED ms=2, FIRST t_us=3094786, MPU_RECOVERED ms=3093, BACKGROUND_READY ms=4083. Окремий `late.uart.log` отриманий через RFC2217 вже після старту: version, status і probe підтвердили 0x68 та 0/0/1000 mg. Це один контрольований модельний запуск, а не реальний час готовності чи властивість фізичного MPU. Колишня baseline lab3 позначена тегом на попередньому commit; новий дослід — доповнення до неї. Фізична flash/power-cut залишаються непідтвердженими.
