# Перевірка збірки VendGuard

03.10.2026 виконано дві чисті збірки. Обидві завершилися з кодом 0; ELF, HEX і BIN мають однакові SHA-256. Помилок і попереджень компілятора в логах немає.

Перевірку виконано через Docker на Mac, архітектура контейнера arm64. Окремий запуск в Ubuntu та UART/LED у Wokwi ще не перевірено.

- Перша збірка: `make build` без наявної папки `firmware/build`.
- Друга збірка: `make clean`, потім `make build` на тому самому образі.
- Docker Engine: `29.6.1`.
- ARM GCC: `10.3.1 20210621`, пакет `15:10.3-2021.07-4`.
- ID образу: `sha256:388b6c161dfa1bb0da0d16edab133d5e1637cbc24bd4cb3a2bdd573175d541e2`.
