# UART VendGuard

USART2 115200 8N1. Команди є ASCII-рядками, завершеними Enter. buffer 48 bytes; довший рядок відхиляється, невідома команда має відповідь UNKNOWN. Це навчальне керування, без автентифікації.

| Команда | Дія |
|---|---|
| guard | Режим охорони |
| service | Режим обслуговування |
| status | Поточні покази, режим, alarm count |
| probe | ID та 6 raw bytes прискорення для зіставлення I²C/UART |
| mpu 69 | Діагностичний перехід до відсутньої адреси, FAULT; інші канали працюють |
| mpu 68 | Повернення правильної адреси та повторна ініціалізація |
| calibrate | Повторне визначення фону нерухомого автомата із закритим темним відсіком |
| journal | 64 останні записи, зі старими sequence і ms |

BOOT/CHECK/READY є самоперевіркою. READABLE GPIO/ADC означає доступність входу, а не діагностику всіх фізичних обривів.

VG EVENT містить seq, ms, category, source, event, value. Категорії INFO/ALARM/FAULT. VG RECORD є повторним читанням журналу і не означає нового спрацювання. ms є часом HAL_GetTick від старту, не календарним часом.

Покази STATUS за imu!=OK є останнім успішним sample, не новим виміром. Детектор отримує valid=false і не використовує їх. Після відновлення MPU повторно накопичує 100 samples фону. LIGHT_READY і BACKGROUND_READY явно позначають завершення калібрування.
