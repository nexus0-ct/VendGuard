# VendGuard

Захист торгового автомата від ударів по корпусу та підозрілого відкриття сервісного відсіку. Звичайна поява покупця сама по собі не створює тривогу.

Власник: Шостак Богдан, ІО-36, №20.

Середовище: Ubuntu 24.04, Docker, C зі STM32 HAL, Wokwi у VS Code. Плата в симуляторі: Nucleo-C031C6.

## Поточний стан

Код містить UART2 115200 8N1 і перемикання LED на PA5 кожні 1000 мс. I²C1 налаштовано, датчиків у схемі немає.

Дві чисті Docker-збірки дають однакові ELF, HEX і BIN. [Логи та SHA-256](docs/build-check.md). Для завершення ЛР1 потрібні демонстрація UART/LED у Wokwi, дослідження компонентів, звіт і відео.

## Збірка й запуск

Команди виконують із кореня проєкту:

```sh
docker --version
docker info
make build
```

Артефакти збірки: `firmware/build/firmware.elf`, `firmware.hex` і `firmware.bin`.

За доступної ліцензії відкрити проєкт у VS Code й виконати `Wokwi: Start Simulator`. Очікуваний UART-вивід: `STM32C031C6 ready`, далі послідовні `tick` приблизно щосекунди. LED змінює стан раз на секунду, повний цикл триває приблизно дві секунди. Запуск у Wokwi ще потрібно перевірити.
